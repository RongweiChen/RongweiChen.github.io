# Fit-Flavor OS · Architecture Deepening Prototype

This folder contains a single-file static prototype that deepens the original Fit-Flavor MVP into an architecture-level product console.

## Included capabilities

- onboarding and device pairing
- analytics overview with 7-day and 30-day metrics
- time-series sodium forecasting with intervention slider
- calibration UI for device bias correction
- OTA upgrade entry
- community ranking based on clone success rate
- health and sustainability impact dashboard
- executable recipe asset library

## Notes

This is a front-end prototype intended for GitHub Pages deployment. The bundled `index.html` contains styles and scripts inline for simple static hosting.
